# Steward app (/app)

Scope: the authenticated product app — Packages, Review, Package detail, Data. Mode: Operate.
Audience: nonprofit preparer, reviewer (signs), program approver. Job: get a monthly billing package to tie out to the cent and signed. Constraint: Steward never signs; preparer ≠ reviewer; synthetic-data badge visible.

## Direction contract

seed: none (direction pinned by the user-approved brief: "mix" of capital.xyz + findyourbeacon.app)

THESIS: The reviewer's desk — one sheet per billing package, exceptions marked in red pen, everything clean stays ink on paper. Refuses the KPI-tile dashboard with charts and coloured cards.

OWN-WORLD: Warm bone paper ground (#EFECE6), white sheets with hairline warm rules, near-black ink. Geist for all UI and numbers (tabular), Newsreader for display lines with an italic accent and for verbatim contract quotes. Black pill primary buttons, quiet outline secondaries. Colour only as state: redpen = not allowed/caught, amber = needs you, green = passes/ready.

STORY: The reviewer sees which package is closest to its due date and what stands between it and a signature; opens it; every failing check names the exact lines; fixes them in Review; returns to a package whose checks are all green; signs.

FIRST VIEWPORT: Packages: one Newsreader sentence ("2 packages need you before Nov 30"), then package sheets sorted by urgency, each with one large claimable amount, status, "5 of 7 checks pass" with a thin bar, due line, preparer/reviewer.

SIGNATURE: Red-pen strike drawn through the bookkeeper's wrong coding in a case; a rubber stamp "SIGNED · name · date" lands on the package header when the reviewer signs.

RISK: Paper + serif is a saturated look; held to display moments only, and the working surfaces (tables, queue, forms) stay plain grotesk and standard controls.
